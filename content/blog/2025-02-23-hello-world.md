# Welcome to Our Blog

This is our first blog post created using the integrated CMS. We're excited to share our journey with you!

## Features

- Markdown support
- Git-based content management
- No authentication required in development
- Multiple CMS options available

## Getting Started

To create or edit content:

1. Navigate to `/tools/cms`
2. Choose your preferred CMS
3. Create or edit content
4. Save changes to see them reflected in Git

Happy blogging!
