# SSOT5001: Micro-Frontend Implementation Guidelines

## Main App Technical Implementation Details

This document provides detailed technical specifications for implementing micro-frontends that match the main application exactly.

### Project Structure

```
├── public/                 # Static assets
├── src/
│   ├── components/         # React components
│   │   ├── ui/             # Reusable UI components
│   │   └── [feature]/      # Feature-specific components
│   │   
│   ├── hooks/              # Custom React hooks
│   ├── lib/                # Utility functions
│   ├── types/              # TypeScript type definitions
│   ├── api/                # API client functions
│   ├── main.tsx            # Entry point for Vite
│   ├── App.tsx             # Main application component
│   └── index.css           # Global CSS
├── vite.config.ts          # Vite configuration
├── tsconfig.json           # TypeScript configuration
├── tailwind.config.js      # Tailwind CSS configuration
└── package.json            # Dependencies and scripts
```

### State Management Pattern

For global state, use Zustand with this pattern:

```typescript
import { create } from 'zustand';

interface StoreState {
  // State properties
  someState: string;
  // Actions
  setSomeState: (value: string) => void;
}

export const useStore = create<StoreState>((set) => ({
  someState: 'initial value',
  setSomeState: (value) => set({ someState: value }),
}));
```

### Entry Point Pattern

Entry point (main.tsx) must follow:

```typescript
import React from 'react';
import ReactDOM from 'react-dom/client';
import { BrowserRouter } from 'react-router-dom';
import './index.css';
import App from './App';

// Vite environment type declaration
declare global {
  interface ImportMeta {
    env: {
      VITE_SUPABASE_URL?: string;
      VITE_SUPABASE_ANON_KEY?: string;
      DEV: boolean;
    };
  }
}

ReactDOM.createRoot(document.getElementById('root')!).render(
  <React.StrictMode>
    <BrowserRouter>
      <App />
    </BrowserRouter>
  </React.StrictMode>
);
```

### Supabase Integration

```typescript
// Initialize Supabase client
const supabaseUrl = import.meta.env.VITE_SUPABASE_URL || 'fallback-url';
const supabaseKey = import.meta.env.VITE_SUPABASE_ANON_KEY || 'fallback-key';
const supabase = createClient(supabaseUrl, supabaseKey);

// Data fetching pattern
const fetchData = async () => {
  const { data, error } = await supabase
    .from('table_name')
    .select('*')
    .order('created_at', { ascending: false });
    
  if (error) {
    console.error('Error fetching data:', error);
    return [];
  }
  
  return data || [];
};
```
