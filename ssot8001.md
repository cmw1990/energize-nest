# SSoT 8001: Well-Charged Project Documentation

## 1. Project Overview

*   **Name:** The Well-Charged App
*   **Goal:** A comprehensive, world-class wellness platform integrating tools for mood, focus, sleep, nutrition, fitness, sobriety, nicotine cessation, and more. Aims to be the only wellness app users need, including features for therapist/dietitian integration and visitor-facing web tools.
*   **Platforms:** Web App (Desktop & Mobile), Mobile App (via Capacitor)

## 2. Technology Stack

*   **Frontend Framework:** React (v18.2.0) with TypeScript
*   **Build Tool:** Vite (v6.2.6)
*   **UI Library:** Shadcn/ui (using Radix UI primitives)
*   **Styling:** Tailwind CSS (v3.4.11)
*   **Routing:** React Router DOM (v6.20.0)
*   **State Management/Data Fetching:** TanStack Query (v5.8.4)
*   **Form Handling:** React Hook Form (v7.53.0) with Zod for validation
*   **Animation:** Framer Motion, Tailwind CSS Animations
*   **Mobile Wrapper:** Capacitor (v7.0.1)
*   **Backend/Database:** Supabase
    *   Authentication
    *   PostgreSQL Database
    *   Storage (presumably)
    *   Edge Functions (implied by `EDGE_FUNCTIONS.md` and `supabase/functions`)
*   **Key Dependencies:** `lucide-react` (icons), `recharts` (charts), `date-fns`, `react-beautiful-dnd` / `@hello-pangea/dnd`, potentially `phaser`, `three`, `react-three/fiber` for games/visualizations.

## 4. Project Structure (`src/`)

*   `App.tsx`: Main application component, sets up providers (Theme, Auth, QueryClient) and defines routes.
*   `main.tsx`: Entry point, renders the `App` component.
*   `components/`: Reusable UI components.
    *   `Layout.tsx`: Main application layout for logged-in users (likely includes navigation).
    *   `AuthProvider.tsx`: Manages Supabase authentication state.
    *   `ThemeProvider.tsx`: Manages application theme (light/dark).
*   `pages/`: Top-level page components corresponding to routes.
*   `routes/`: (Potentially) Route configuration, though main routing is in `App.tsx`.
*   `services/`: (Potentially) Contains functions for API calls/business logic (needs further inspection).
*   `hooks/`: Custom React hooks.
*   `utils/`: Utility functions.
*   `lib/`: Library integrations/configurations (e.g., potentially shadcn config).
*   `styles/` / `index.css` / `App.css`: Global styles and Tailwind base styles.
*   `types/`: TypeScript type definitions.
*   `integrations/`: Contains Supabase client and potentially other third-party integrations.
    *   `supabase/client.ts`: Supabase client initialization.
    *   `supabase/types.ts`: Auto-generated Supabase database types.
*   `assets/`: Static assets like images, fonts.
